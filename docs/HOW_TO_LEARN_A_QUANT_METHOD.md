# 怎么学一个量化方法(可复用 playbook)

> 目标是同时拿到三样东西:**代码能力**(从零实现关键路径)、**面试能力**
> (能被追问三层不倒)、**记录**(数字可复算、口径可防御)。
> 本仓 GPTQ(EXP-001《GPTQ 从零实现》 + docs/theory/01_gptq.md)是第一份按此执行的样例;
> 此前的 AWQ / SmoothQuant 实践缺的是第 4、5 步——补齐后同样入此模板。

## 第 1 步 · 先问"它在优化什么目标"(30 分钟,论文只读三处)

读摘要、方法节的**目标函数**、实验表的 setup 行。一句话写下:
- 它最小化什么?(GPTQ:‖WX−QX‖²;AWQ:显著通道的量化损失;
  SmoothQuant:激活可量化性)
- 它需要什么输入?(校准集?梯度?什么都不要?)
- 它作用在哪?(W?A?KV?粒度是 tensor/channel/group?)
这三问的答案就是面试第一层回答,也决定了你要实现哪些组件。

## 第 2 步 · 手推核心公式一次(纸上,不超过 1 页)

推不动的地方就是面试必挂的地方。GPTQ 要推的只有一个:
"量化第 j 列后,如何更新剩余列使输出误差最小"——拉格朗日 + 二阶展开,
解出 δ = −err/[H⁻¹]_jj · [H⁻¹]_{j,·}。推完立刻自问:
每个符号的 shape 是什么?哪些量全行共享?(这类 shape 问题是追问高频区。)

## 第 3 步 · 从零实现关键路径,而非跑通别人的仓(半天)

规则:**框架代码可以抄,算法主循环必须自己写**。
- 定义"关键路径":GPTQ = H 累积 + Cholesky 逆 + 列循环补偿;
  AWQ = grid search best scale/clip;SmoothQuant = s 的计算与折叠。
- 在 0.5B 级小模型上端到端(本机 Qwen2.5-0.5B,单卡分钟级),
  不要一上来就 7B——迭代速度决定学习深度。
- 与参考实现**对齐三个数值锚点**(不是抄代码):H 的缩放方式、阻尼、
  组参数取自补偿后权重。对不齐的地方就是你理解的洞。

## 第 4 步 · 设计对照,让"方法本身的贡献"可分离(这是最值钱的一步)

一个方法的价值 = 它相对"最笨基线"的增量。固定其余一切,只开关核心机制:
- GPTQ 的对照 = **同一量化网格的 RTN**(唯一差异:误差补偿开/关)
  → PPL 差值就是二阶补偿的贡献,一个数字讲清方法价值。
- AWQ 的对照 = 无 scale 直接 INT4;SmoothQuant 的对照 = 不迁移直接 W8A8。
这与 CUDA 项目的"控制变量反例归因"是同一方法论——面试官会认出来。

## 第 5 步 · 闭环到部署与评测(否则故事断在离线侧)

- 精度:PPL 用**固定协议**(窗/步/同计分 token 集,写进结果 JSON),
  绝对值不跨协议比较,只做臂间相对比较。
- 速度:量化的收益兑现在 kernel(W4A16 → Marlin 反量化融合,decode
  带宽减半)——引用自己的 serving 实测(vllm/experiments#EXP-016《D4 FP8 vs W4A16 同卡对比》),
  并能讲反例(大 M 下反量化开销显形,FP8 反超 TTFT)。
- 正确性:real quant 打包 ↔ fake quant 逐元素一致(pack_check 断言),
  这是"我真的实现了存储格式"的证据。

## 第 6 步 · 按 CORE 记录 + 五节原理笔记(半小时,当场写)

- records/EXP-NNN 八节:假设写成可证伪("GPTQ 的 PPL 显著优于同网格 RTN,
  接近 fp16"),阈值跑前锁定。
- docs/theory/NN_topic.md 五节:一句话结论 / 机制(自己的话)/
  **本项目实证(必须指向自家 EXP 数字)** / 面试追问 Q&A / 延伸锚点。
  Q&A 节按"为什么这样设计→数值细节→与相邻方法的边界→部署衔接"四层备。
- 简历句只从 records 的数字生成,措辞过 LEDGER.md 红线表(状态与措辞唯一权威)。

## 检验标准(三问自测)

1. 白板 10 分钟能从目标函数推到主循环伪码吗?(代码能力)
2. "它和 X 方法的区别/能不能叠加"能秒答吗?(面试第二层)
3. 报告里每个数字能指到 data/raw 的文件吗?(记录)
