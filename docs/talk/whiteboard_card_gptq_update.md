# 白板推导卡 · GPTQ 逐列补偿公式


**推导目标**:量化第 j 列后,如何更新剩余列使输出误差最小。
1. 目标:min‖WX − ŴX‖²,H = 2XXᵀ(自协方差,阻尼 λI 保正定)。
2. 按 OBS:固定 w_j→q_j,产生误差 δ=(w_j−q_j);其余列的最优补偿
   Δw = −δ · [H⁻¹]_{:,j} / [H⁻¹]_{jj}。
3. 工程化(GPTQ 的两步):①对 H⁻¹ 做 Cholesky 得上三角 U,
   逐列只用 U 的当前行——O(d²) 而非每列重解;②blocksize 分块延迟更新,
   块内即时补偿、块间批量传播(与 group_size 对齐避免跨组污染,EXP-001)。
4. **面试点**:补偿只往"还没量化"的方向传播(上三角结构的含义);
   实测二阶补偿收回 RTN 损失 61.6%(控制变量,EXP-001)。
