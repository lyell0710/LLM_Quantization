# 量化三法讲解提纲(约 30 分钟,自家数字全程带跑)

> 讲给自己/面试官的顺序不是论文顺序，是**问题驱动**顺序。每一节：先抛问题 → 给机制 → 甩自家数字 → 备一个反问。全部数字出处：README 主对照表（EXP-001/002/003）。

## 0. 开场一分钟:为什么量化(接 D1 机理)

decode 是权重带宽受限（自家 vllm/experiments#EXP-014《D1 MoE decode 分解》：GDDR6X ~1008GB/s， dense 7B bs=1 实测贴 roofline 77%）→ 权重每少一半 bit，decode 就快约一倍的物理空间。所以先有 W4A16（只压权重），后有 W8A8（算力路径也换 INT8）。 **两个赛道，压的东西不同，快的 regime 不同**——这是全场的骨架。

## 1. 基线:RTN 为什么不够(2 分钟)

- 最近取整，优化目标是 ‖W−Q‖²——但推理在乎输出不是权重。
- 自家数字：INT4-g128 RTN 把 0.5B 的 PPL 从 11.92 打到 14.12(+2.20)。
- 反问预备：那 per-group 已经是 RTN 的强化了，为什么还不够？（答：粒度解决"组间尺度差"，解决不了"组内谁更重要"。）

## 2. GPTQ:改"怎么取整"(8 分钟,白板主战场)

- 问题重述：min ‖WX−QX‖²。激活大的输入维，权重误差被放大。
- 白板推导链（10 分钟版见 theory/01 §2）：H=2XXᵀ → 逐列量化 → 误差按 H⁻¹ 补偿到未量化列 → Cholesky 上三角一次算好 → 128 列块化。
- 自家数字：**PPL 12.76，收回 RTN 损失 61.6%**——而且这是控制变量数字（同一网格、同 find_params，唯一差异=补偿开关）。
- 实现细节弹药：组参数必须取自"补偿后"权重（blocksize=group_size 对齐）； 阻尼 1% 防病态；全行共享一次 Cholesky（H 与行无关）。
- 反问预备：act_order 是什么/为什么小模型收益小（theory/01 Q&A）。

## 3. AWQ:改"在哪个坐标系取整"(6 分钟)

- 恒等变换 y=X·(s⁻¹·s·W)ᵀ：给激活大的维的权重乘 s 再量化——显著权重占更细的格。α 网格搜，输出 MSE 裁决。
- 自家数字：**PPL 13.41，收回 31.9%**；per-layer α 中位 0.30、两层飙到 0.95——保护强度按层自适应，这个分布图比结论好讲。分布图：`figures/fig1_awq_alpha_dist.png`（`scripts/plot_alpha_dist.py` 从 `data/raw/EXP-002/awq_g128.json` 重算，2026-08-24）。
- 与 GPTQ 的关系：改坐标系 vs 改取整，正交可叠加——自家叠加臂 **12.7376(62.6%)**，比纯 GPTQ 好但只有 +1.0pp：方向成立， 0.5B 上高度重叠，**分寸感就是可信度**。
- 部署折叠约束（必考）：评测时 per-linear s 合法；runtime 折进 RMSNorm 时 q/k/v 必须共享 s。能讲清这条=真做过。

## 4. SmoothQuant:难度搬家,不是取整技巧(6 分钟)

- 换赛道：W8A8 的病在激活 outlier（固定通道、百倍幅值，per-token scale 被绑架）；per-channel 量化激活又与 GEMM 不相容 → 只能把难度搬去权重侧。
- s_j = actmax^α / wmax^{1−α},α 是天平。
- 自家数字（最有讲头的一组）：naive W8A8 仅 +0.21 PPL——**0.5B 的 outlier 温和，可搬的难度本来就少**；α=0.75 收回 48%，α=0.25 反而更差（迁移不足先伤权重）。→ 反面印证论文价值随模型规模增长， "我在小模型上看到了它为什么在大模型上才重要"。
- 边界句：AWQ 的 s 和它形似，方向相反（放大显著权重 vs 缩小激活难度）， 目标物不同（W4 内部分配 vs A8 可行性）。

## 5. 闭环:量化后怎么跑得快(3 分钟,接 serving 实测)

- W4A16 兑现：Marlin 反量化融合进 GEMM——自家 serving 实测（vllm/experiments#EXP-016《D4 FP8 vs W4A16 同卡对比》）decode 快 23–48%；但大 M(prefill)反量化开销显形，FP8 在 c128 TTFT 反超——**没有全域胜者，按 regime 选型**。
- 收尾一句：离线算法（本仓三法）→ 存储格式（INT4 打包，pack↔fake 断言） → kernel（Marlin/FP8 路径）→ serving 数字，链路每一环都有自家实测。
